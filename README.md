# Alantria Launcher

A free launcher for the **Alantria** Minecraft: Java Edition server (`alantria.mcsh.io`).
It installs Minecraft 1.21.1 with NeoForge, keeps the server's modpack up to date, and launches the official game.

**Download:** [AlantriaLauncher.exe](https://github.com/Sedulous-Dev/alantria-pack/releases/download/launcher/AlantriaLauncher.exe)

- Players sign in with their own Microsoft account (Microsoft device code flow). A copy of Minecraft: Java Edition is required.
- Sign-in tokens stay on the player's PC, encrypted with Windows DPAPI. Nothing is sent anywhere except Microsoft/Xbox/Minecraft services.
- No ads, no payments.

This repository holds the modpack files the launcher downloads (`manifest.json` + `files/`). It is updated by the server owner.
